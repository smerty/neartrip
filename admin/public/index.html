Base position and ellipsoidal height are detected automatically from RTCM 1005/1006. Manual coordinates are an optional fallback. A base joins nearest-station selection after its reported position settles and data is flowing. This checks stream stability; it does not survey the base or establish coordinate accuracy.

Measured protection

NTRIP IP activity & bans

Review repeated login failures and malformed requests before taking action. Normal disconnects, missing GGA, and stale correction streams never trigger automatic bans.

Automatic softbans Opt-in

Active authenticated connections, IPs with a successful login in the last 30 minutes, loopback, and exemptions are protected from automatic bans. Manual bans still take priority. Addresses are the listener's TCP peers; a proxy or shared NAT may represent multiple clients.

Manual action
